Nhập ý tưởng bằng tiếng Việt → nhận prompt tiếng Anh hoàn chỉnh (qua Cline API)

🔍 Đang kiểm tra proxy local...
Tool chạy local — key và model cấu hình trong file .env ở root repo, server proxy đọc tự động. Chạy: node prompt-generator/server.mjs rồi mở http://localhost:PORT.
